## 🖥️ What zigpty is

zigpty is a small PTY library for Node.js. It helps an app talk to a terminal session on the same computer. It is built in Zig and works on Windows, Linux, macOS, and Android.

You can use it in two ways:

- as a Node.js library
- as a standalone Zig package

This project fits cases where an app needs shell access, terminal control, or a process that behaves like a real terminal program.
